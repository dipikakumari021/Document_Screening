Tech Stack Used

Next.js 16 React framework for full-stack web apps with App Router
FastAPI Python AI microservice exposing the OCR endpoint
TypeScript Superset of JavaScript with static type safety
Tesseract OCR Reads MRZ text from passport images at 99.7% accuracy
Tailwind CSS v4 Utility-first CSS framework for rapid UI styling
MongoDB Atlas Cloud NoSQL database for screening records & users
JWT + bcrypt Secure session tokens & password hashing for officer auth
Docker Containerizes the Python AI service for easy deployment
